Sniper rifle sounds. Drop .wav or .ogg files in this folder named:
  fire_01.wav, fire_02.wav ...      the gunshot (until then it borrows the pistol's)
  reload_01.wav ...                 reloading
  switch_01.wav ...                 bringing the rifle out
  scope_in_01.wav ...               raising the scope to your eye
  scope_out_01.wav ...              lowering it
Several files with the same start (fire_01, fire_02) = one is picked at random each time.
