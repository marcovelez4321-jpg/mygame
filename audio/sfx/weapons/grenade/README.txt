Grenade sounds. Drop .wav or .ogg files in this folder named:
  throw_01.wav ...     the throw (whoosh)
  tick_01.wav ...      the warning beep, played every time it flashes
  bounce_01.wav ...    hitting the floor or a wall (a few different ones sound best)
  switch_01.wav ...    taking a grenade out
Several files with the same start (bounce_01, bounce_02) = one is picked at random each time.
